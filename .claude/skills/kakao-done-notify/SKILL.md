# 카카오톡 완료 알림

교수님은 작업이 길어지면 화면을 보고 있지 않는다. **시킨 일이 끝났으면 카카오톡 나와의 채팅으로 한 줄 알린다.**

---

## 1. 도구를 먼저 불러온다

도구 이름 앞에 붙는 서버 id 는 바뀔 수 있다. **이름을 외워서 쓰지 말고 키워드로 찾는다.**

```
ToolSearch  query: "KakaotalkChat MemoChat"   max_results: 3
```

- 찾은 도구를 `message` 하나로 호출한다
- **메시지는 최대 200자다.** 넘으면 잘린다 — 길면 줄여서 보낸다
- 도구가 목록에 없으면 보내지 않는다. 보낸 척하지 말고 "카카오톡 도구가 이 세션에 없다"고 한 줄 적는다

---

## 2. 언제 보내는가

**보낸다**

- 교수님이 시킨 일 하나가 **끝났을 때** — 자료를 만들었고, 코드가 돌았고, 커밋까지 올라갔을 때
- 여러 세션에 나눠 준 일이 **다 돌아왔을 때** (한 세션 끝날 때마다가 아니라, 묶음이 끝났을 때)
- **막혀서 멈출 때** — 교수님의 답을 기다려야 더 갈 수 있을 때
- 실패했을 때도 보낸다. 성공만 알리는 알림은 믿을 수 없다

**보내지 않는다**

- 한 턴 안의 중간 단계마다 (파일 하나 고칠 때마다, 테스트 한 번 돌릴 때마다)
- 질문에 말로만 답한 턴, 몇 번의 도구 호출로 끝난 짧은 일
- 같은 내용을 두 번 — 이미 보낸 것을 다시 보내지 않는다
- 자식 세션이 각자 보내는 것 — **알림은 교수님과 대화하는 세션 하나만 보낸다**

---

## 3. 무엇을 적는가

200자 안에 이 셋을 담는다.

1. **무엇이** 끝났는가 (일의 이름)
2. **결과** — 숫자로 (실측값, 몇 개, 성공/실패)
3. **어디에 있는가** — 커밋 해시 또는 파일 이름. 안 끝난 것이 있으면 그것도

문체는 볼트와 같다 — 개조식, 담백하게. 이모지는 쓰지 않는다.

### 보기

```
[캡스톤] 도킹 퓨어 스웨이 — 스테이션 1·2·3 전부 진입 성공.
왼쪽 가제보·오른쪽 MATLAB GUI 녹화 남김. 커밋 a1b2c3d, origin/main.
```

```
[캡스톤] 부표 게이트 — 카메라 중간점 헤딩까지는 되는데
WP1 위치유지에서 오버슛 2.4 m. 원인 찾는 중, 아직 안 올렸습니다.
```

```
[캡스톤] 녹화 지침 정리 완료 — 영상 29개 확인, 오른쪽 칸은 MATLAB GCS 로 결정
(RViz2 에 명령값이 없음). 커밋 085da33.
```

> [!important]
> **안 된 것을 된 것처럼 보내지 않는다.** 자식 세션의 보고는 증거가 아니다 — 커밋이 `origin/main` 에 있는지, 파일이 실제로 있는지 확인한 뒤에 보낸다.

---

## 4. 넣지 않을 것

- 이메일 주소, 전화번호 등 개인정보
- 전체 경로 (`C:\Users\admin\...`) — 저장소 기준 상대 경로로 적는다
- 긴 로그·오류 전문. 한 줄로 줄이고 자세한 것은 화면에 남긴다

---

## 5. 턴 마무리 순서

1. 일이 끝났는지 확인한다 (`git status` 깨끗, 커밋이 원격에 있음, 가제보 잔여 프로세스 0)
2. `mcp__ccd_turn__wrap_up` 을 부른다
3. 카카오톡 도구로 한 줄 보낸다
4. 교수님께 드릴 답을 화면에 쓴다 — 카톡은 알림일 뿐, 답을 대신하지 않는다
