# 캡스톤디자인 볼트 — 일하는 방식

이 볼트는 **배포하는 것과 기록하는 것이 같은 파일**이다. `10-주차별-강의자료/` 의 MD 를
학생이 그대로 받는다. 그래서 "일단 써 놓고 나중에 다듬는다" 가 성립하지 않는다.

> [!important] 한 문장으로
> **모든 수치는 실행해서 얻고, MD 를 고쳤으면 PDF 를 다시 뽑고, 문서를 옮겼으면 README 를 고친다.**

형식 규칙(폴더 구조·문체·프론트매터·콜아웃)의 **원본은 `CLAUDE.md`** 다. 이 스킬은
그것을 **어떤 순서로 실행하는가**를 담는다. 둘이 어긋나면 `CLAUDE.md` 가 이긴다.

> [!important] 새 업무 방식이 생기면 **그 자리에서** 스킬에 적는다
> 말로 지침이 오지 않아도 된다. 도구를 하나 만들었거나, 확인 절차를 하나 늘렸거나,
> 같은 지뢰를 두 번 밟았으면 끝내기 전에 이 스킬에 넣는다. 나중에 몰아서 하지 않는다.
> - 기계로 거를 수 있는 것은 **`vault_check.sh` 에 절로 내린다** — 말로만 두지 않는다
> - 지침을 받으면 순서대로 ① 이 스킬 ② 해당 `references/*.md` ③ `CLAUDE.md`
>   ④ 이미 나간 `.md` 전부 ⑤ **PDF 재생성** ⑥ `vault_check.sh` → 0 건
>
> 대학원 GradCourse 볼트 `standing-orders.md` §0-0·§0-1 에서 가져옴 — 2026-09-24

> [!important] 학부 수업이다 — **최대한 쉽게, 내용은 빠뜨리지 않고**
> 교수 지시다. 한 주차에 새 개념은 **셋까지**, 넘치는 것은 `20-지식/` 지식카드나
> `30-환경/` 가이드로 뺀다. 어려움은 **내용의 깊이**에서 나와야 하고 **설명의 밀도**에서
> 나오면 안 된다 → `references/difficulty.md`

## 1. 어길 수 없는 것

1. **수치는 실행 결과다.** 오차·시간·반경·RMS 를 추정으로 쓰지 않는다.
   반드시 **구간을 명시**한다 ("전 구간" 과 "초기 5초 제외" 는 다른 숫자다).
2. **MD 를 고쳤으면 PDF 를 다시 뽑고, 자료대로 한 번 돌려 본다.**
   세션 끝의 Stop 훅이 `_tools/pdf_sync.sh` 로 자동 처리하지만, **작업 중에도 직접 돌려 확인한다.**
   훅은 마지막 안전망이지 면허가 아니다 — PDF 뷰어가 파일을 열고 있으면 훅도 실패한다.
   `_tools/verify_wNN.sh` → **FAIL 0**. 두 파일이 어긋나거나 명령이 안 되면 학생이 막힌다.
3. **`10-주차별-강의자료/` 와 `80-과제/` 에 내부용 메모를 쓰지 않는다.** 그건 `00-운영/`.
4. **HTML 슬라이드 덱을 만들지 않는다.** 요청받지 않는 한 `html-slide-deck` 스킬 금지.
5. **개조식·정식 교재 어조.** 1·2인칭 금지, 시점 표현("오늘") 금지, 장식 기호 금지.
6. **한 주차에서 고친 규칙은 전 주차에 적용한다.** 배치·문체·형식·도구가 바뀌면
   그 주차만 고치고 끝내지 않는다. 전수 조사 표를 먼저 만든다 → `references/vault-wide-update.md`
7. **폴더명의 `[2026-2]` 대괄호** — PowerShell `-LiteralPath`, bash 는 `find -path "./[2025]*"` 대신
   `*ROS2_VRX_Gazebo_Simulink*` 로 우회한다.
8. **만든 모델은 반드시 자료에 나온다.** `WNN_simulink/` 에 모델을 만들어 놓고
   주차 MD 가 한 번도 언급하지 않으면, 학생에게는 **없는 것과 같다.**
   모델마다 (1) 도면 그림 (2) 무엇을 보는 모델인지 (3) 실행 순서
   (4) **실측 결과와 그것을 어떻게 확인하는가** 를 적는다.
   3주차가 모델 셋을 만들어 놓고 한 절도 쓰지 않은 채 있었다 (2026-09-17 발견).

> [!tip] 점검하는 법
> 모델 이름이 그 주차 MD 어딘가에 나오는지만 본다. 파일 이름(`SB7_...`)과 주차
> 폴더(`W06_0_simulink`)가 다를 수 있으므로 **폴더로** 주차를 찾는다.
> ```bash
> for f in 10-주차별-강의자료/*_simulink/*.slx; do
>   n=$(basename "$f" .slx)
>   w=$(basename "$(dirname "$f")" | sed 's/_simulink$//')
>   grep -qls "$n" 10-주차별-강의자료/${w}*.md >/dev/null 2>&1 \
>     || echo "자료에 없음: $n"
> done
> ```


9. **모델의 기본값을 바꾸면, 그 모델이 낸 숫자를 쓰는 곳을 전부 다시 잰다.**
   본문 표, 콘솔 출력 블록, 그림 안의 표(TikZ), 지식카드, 주차 요약까지다. 숫자로 찾는다.
   ```bash
   grep -rn "1\.777\|5\.263" --include=*.md --include=*.tex .     # 옛 숫자 전부
   ```
   2026-09-18 — 5주차 전환 판정 기본값을 바꾼 뒤 `W05_compare` 표가 옛 값 그대로 남아,
   네 줄 중 셋이 바뀌고 **결론 하나**("조류에서 3.0 배로 벌어진다")가 틀려 있었다.
   숫자가 바뀌면 그 숫자에 기대던 **문장**도 다시 읽는다.
10. **스크립트로 조건을 바꿀 때는 모델이 실제로 읽는 변수를 바꾼다.**

    setup 을 부른 **뒤에** `current_direction` 만 바꾸면 아무 일도 일어나지 않는다.
    2026-09-18 — 이렇게 잰 "동쪽 조류" 표가 실은 북쪽 조류였다. 학생은 setup 파일을 고치므로
    다른 숫자를 보게 된다. 파생 변수가 있는지 setup 에서 확인하고 **둘 다** 바꾼다.
11. **다른 주차를 가리키는 문장은 강의계획서와 맞춰 본다.**
    "8주차에서 Nomoto 로 유도한다" 같은 약속은 계획서가 바뀌면 조용히 틀린다.
    2026-09-18 에 14곳이 틀린 주차를 가리켰고, 그중 넷은 **어디에도 없는** 내용을 약속했다.
    ```bash
    bash .claude/skills/capstone-lecture-vault/scripts/vault_check.sh --refs
    ```
    각 문장 옆에 그 주차의 **실제 제목**이 찍힌다. 제목과 약속한 내용이 맞는지만 보면 된다.
12. **한 글자가 두 뜻이면 두 번째 뜻이 처음 나오는 자리에 경고표를 둔다.**
    바꿀 수 없는 경우가 많다 — 논문 기호($r$ 반경), 관례($N$ 북쪽). 대신 모르고 지나가게 두지 않는다.
    이 볼트에서 겹치는 글자와 둔 자리는 `references/lecture-md.md` §기호 겹침에 있다.


13. **LaTeX·경로가 든 파일을 셸 치환(`sed -i`, `perl -pi`, 셸 heredoc 속 파이썬)으로 고치지 않는다.**
    `\times` 의 `\t` 가 TAB 으로, `\lvert` 가 `vert` 로, `\rvert` 의 `\r` 이 줄바꿈으로 바뀐다. 오류 없이 조용히 깨진다.
    2026-09-18 — 6주차 표의 `$\times 1.6$` 이 `$<TAB>imes 1.6$` 이 됐고, 한 줄은 `\le` 가 `e` 가 됐다.
    Edit 도구를 쓰거나, 파이썬 스크립트를 **Write 로 파일에 써서** `py 파일.py` 로 돌린다 (raw string).
    고친 뒤 `grep -cP '[\x00-\x08\x0b-\x1f]'` 로 제어문자가 0 인지 본다.
14. **물결표 이스케이프는 두 방향이다.** 본문 `~` → `~`, 코드 안 `~` → `~`.
    콜아웃 안 코드 블록(`> ```)도 코드다. 닫히지 않은 펜스 하나가 뒤 전체를 뒤집는다.
    `perl _tools/escape_tilde.pl --check` 가 두 방향과 홀수 펜스를 모두 잡는다 (2026-09-18, 명령 27곳이 깨졌었다).
15. **VRX 스폰 위치를 고정값으로 믿지 않는다.** 같은 VRX 2.4.0-2 인데 설치마다 ENU $y$ = 162 / 200 이었다.
    `W05~W08_vrx_run` 이 ground truth 첫 샘플로 원점을 잰다. 대조 궤적이 **평행하게** 떨어지면 원점, **겹치는데
    이격이 직선으로 커지면** 위상(페이싱)이다.
16. **배선 정리·리팩터 뒤에는 VRX 모델도 돌려 본다.** 오프라인 대조만으로는 VRX 쪽 부호 블록이 빠진 것을 못 잡는다.
    2026-09-17 정리 커밋이 8주차 `pos` 앞의 `Gain(-1)` 을 지웠고, 오프라인 26개 "차이 0" 검증은 통과했다.
17. **결과 그림을 저장할 때 `gcf` 를 쓰지 않는다.** 그리는 함수가 창을 둘 이상 열면 마지막 창(추진기)이 저장된다.
    그리는 함수가 핸들을 돌려주게 하고(`S.fig`) 그것을 저장한다. 5\~7주차 VRX 결과 그림 셋이 그렇게 틀려 있었다.
18. **학생 입장 검토는 주차마다 에이전트 하나, 읽기 전용으로 돌린다.** 결과는 파일로 받아 두고
    (`scratchpad/review/WNN.md`), 텍스트 수정과 코드·재측정을 나눠 진행한다. 텍스트 담당은 수치·코드를 건드리지 않는다.
19. **북·동 위치는 $x$ (북), $y$ (동). 코드 이름은 `x_n`, `y_n`.** $N$ 은 요 모멘트 전용, $E$ 는 위치로 쓰지 않는다.
    $\boldsymbol{\eta} = [x,\ y,\ \psi]^{\mathsf T}$, 웨이포인트 $(x_k, y_k)$, 선체 축 좌표는 $x_b,\ y_b$, ENU 성분은 $x_{\text{ENU}}$.
    그림 축은 "y (동쪽) [m]" · "x (북쪽) [m]". 교수 지시 (2026-09-19) — `pn`/`pe`·`N`/`E` 가 섞여 전면 교체했다.
20. **예제마다 오프라인 운동모델로 먼저, VRX 는 그다음.** 같은 제어기·버튼 블록을 같은 함수로 만들고

21. **VRX 에서 첫 유효 샘플은 시각으로 자르지 않는다.** odom 도착이 0.5 s 를 넘길 때가 있다 (2026-09-19 7주차).

    0.3\~2.6 m 로 달라지므로 판정은 정착 후 오차 · 정상상태 속도로 한다.

    원본은 `_templates/강의자료저장소블록.md` — 저장소 두 개(강의자료 `Capstone-Design`, 예제 패키지
    `usv_basics`)의 주소, 처음 한 번 `git clone`, 매주 `git pull`,
    `git log --oneline -10` 으로 갱신 내역 보기. **문서마다 고쳐 쓰지 않는다** (참조 강의 블록과 같은 규칙).
    자리는 참조 강의 블록 바로 뒤. 주차 문서 전부와 `00-운영` 문서에 들어가며 `vault_check` 16 번이 센다.
    그리고 **주차 문서의 "시작 전 확인" 첫 줄은 강의자료 `git pull` 이다.** 학생은 강의자료 저장소를 2주차 2-6 에서
    WSL 에 한 번 clone 하고 매주 `cd ~/Capstone-Design && git pull` 로 갱신한다 (20-지식 카드
    `강의자료는-한-번-받고-git-pull-로-갱신한다`). 새 주차 문서를 만들 때도 이 줄을 넣는다.
    MATLAB 은 `\\wsl.localhost\Ubuntu-22.04\home\<사용자명>\Capstone-Design\...` 경로로 연다 (2026-09-19 확인).
23. **한 주차 안의 절 순서는 "앞 절만 알면 뒤 절이 읽히는" 순서다.** 개념·기호·블록·명령·파일은
    **처음 쓰이는 자리보다 앞에서** 설명된다. 뒤에서 정의된 것을 앞에서 쓰고 있으면 절을 **앞뒤로 옮겨**
    맞춘다 — 내용은 더하거나 빼지 않는다 (교수 지시 2026-09-19). 옮긴 뒤에는 절 번호와 그 번호를 가리키는
    문장(같은 주차 · **다른 주차** · 강의계획서 · 지식 카드)을 모두 고친다. 템플릿 골격(학습 목표 → 이론 →
    실습 → 요약 → 진도 체크 → 과제 …)의 자리는 그대로 두고 그 **안에서** 옮긴다. 새 절을 쓸 때도 이 순서로 넣는다.
24. **첫 페이지 맨 위는 이번 학기 녹화 강의 재생목록이다** (교수 지시 2026-09-24).
    원본 `_templates/녹화강의블록.md` — `https://youtube.com/playlist?list=PLK_f1-krzJG8`.
    H1 **바로 뒤**, 참조 강의 블록보다 **위**에 둔다. 참조 강의(지난 학기까지의 선수 과목)와 혼동되지 않게
    "이번 학기 본 수업 녹화" 임을 블록 안에서 밝힌다. 주차 문서·부록·`00-운영` 전부. `vault_check` 16 번이 센다.
25. **제어 주차 문서는 "원리 바로 아래 예제" 로 쓴다** (교수 지시 2026-09-24).
    한 절 = 현상 → 결과 식 → **유도 한 줄씩**(각 줄에서 무엇을 했는지 한 줄 설명) → **예제** → 정리 콜아웃.
    예제 블록은 **세 가지를 반드시** 갖춘다 — ① 모델 도면(회로가 보이는 서브시스템 도면 포함)
    ② 여는 법·실행 명령 ③ **결과 그래프**와 그래프 읽는 법, 그리고 실측표로 위 유도를 검산한다.
    유도를 부록으로 빼지 않는다. 쪽수가 늘면 그림을 줄이지 유도를 줄이지 않는다 (4주차 실제 97쪽).
26. **제어 모델은 실시간 화면을 갖춘다** (교수 지시 2026-09-24).
    3주차 `W03_animate` 처럼 궤적 위에 **선체와 선수 방향**을 그리고, 상태값($u$, $v$, $r$, $\psi$, $F_L$, $F_R$)을
    실시간으로 보여 준다. 제어 주차는 여기에 **지령 대비 응답**을 겹쳐 그린다 — $u_{\text{ref}}$ ↔ $u$,
    $\psi_{\text{ref}}$ ↔ $\psi$. **오프라인과 VRX 쌍둥이가 같은 화면 함수를 쓴다** (규칙 20 과 같은 이유).
    그 화면의 캡처를 그 주차 자료에 싣는다 — 모델이 무엇을 보여 주는지는 도면이 아니라 **화면**이 말한다.
27. **VRX 는 3주차 경량 모델을 기준으로 띄운다** (교수 지시 2026-09-21).
    `10-주차별-강의자료/W03_vrx_lite/` 의 `wamv_lite.urdf` + `run_vrx.sh` + `--render-engine-gui ogre`.
    카메라·LiDAR 를 끄면 RTF 가 0.39 → 0.99 로 오르고 흔들림이 사라진다 (2026-09-24 실측, 표준편차 0.002).
    카메라·LiDAR 가 필요한 절(3주차 토픽 탐색, 9주차 전수조사)만 기본 명령으로 띄운다.
    **`ROS_DOMAIN_ID` 는 전 주차 7** — `W0X_setup.m` 과 `~/.bashrc` 가 어긋나면 토픽이 하나도 안 보인다.

> ```
> 대괄호를 씌우지 않으면 **자기 명령줄이 패턴에 걸려** 셸이 먼저 죽는다.

## 5. 작업이 끝나면 GitHub 로 올린다

자료를 고쳤으면 **커밋하고 푸시하는 것까지가 한 작업**이다. 커밋만 해 두면 다른
PC 와 어긋나고, Dropbox 동기화와 git 이 서로 다른 상태를 들고 있게 된다.

```bash
bash _tools/git_autopush.sh "직접 쓴 커밋 메시지"    # 커밋 + 푸시
bash _tools/hook_stop.sh                             # PDF 동기화까지 함께
```

- 세션이 끝날 때 **Stop 훅**이 `hook_stop.sh` 를 부른다 — MD→PDF 동기화 후 커밋·푸시
- 훅이 돌았는지 확인 : `git rev-list --count origin/main..HEAD` 가 **0**

> [!caution] 볼트 밖 폴더에서 세션을 열면 훅이 걸리지 않는다
> Claude Code 는 **연 폴더의** `.claude/settings.json` 만 읽고 상위 폴더로 거슬러
> 올라가지 않는다. 볼트와 저장소 루트에 훅이 있어도, 다른 폴더에서 열면 아무것도
> 걸리지 않고 커밋이 조용히 쌓인다 (2026-09-17 에 두 커밋이 밀려 있었다).
>
> - 되도록 **볼트 폴더에서 연다**
> - 다른 폴더를 써야 하면 그 폴더에도 `.claude/settings.json` 을 두고 훅을 건다
> - 어느 쪽이든 **끝내기 전에 미푸시 커밋 수를 직접 확인한다**

올리면 안 되는 것은 `.gitignore` 가 막는다 — 학생 제출물, 저작권이 남에게 있는
자료, 빌드 산출물(`slprj`, `.slxc`). 스테이징한 목록에 그런 것이 보이면 **멈춘다.**
