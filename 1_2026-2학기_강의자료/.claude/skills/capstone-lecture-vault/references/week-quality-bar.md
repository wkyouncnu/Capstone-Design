## 2. "정상 출력" 을 쓰는 형식

명령 하나에 결과 하나를 붙인다. 결과는 **실제로 받은 것**이어야 한다.

````markdown
```bash
ros2 topic echo --once /wamv/sensors/gps/gps/fix
```

- 정상 출력

```
latitude: -33.72242651051122
longitude: 150.67398709806955
altitude: 1.2479525180533528
```

| 읽는 법 | 뜻 |
|---|---|
| 위도 −33.72 / 경도 150.67 | 시드니. 월드가 맞다는 뜻 |
| 고도 1.248 | GPS 가 z = 1.30 m 에 달린 것과 일치 |
````

- **출력만 붙이고 끝내지 않는다.** "이 숫자가 왜 이 값인지" 를 한 줄이라도 단다
- 값이 길면 앞부분만 싣고 `...` 로 자른다

## 3. 화면 캡처

### 언제 캡처하는가

| 상황 | 캡처 |
|---|---|
| 설치·기동이 성공한 순간 | **필수.** "이 화면이 나오면 성공" |
| GUI 도구(RViz2·rqt·Gazebo·Simulink) | 필수 |
| 터미널 텍스트 출력 | 캡처하지 않는다. **코드블록으로** 싣는다 |

### 무엇을 캡처하는가 — 도구가 나오면 그 도구의 화면을 넣는다

| 문서에 나오는 것 | 넣어야 할 화면 |
|---|---|
| VS Code 설치·사용 | 탐색기 트리 + 편집기 + 상태바가 보이는 실제 창 |
| Claude Code · 에이전트 | 실행 화면 (대화 내용은 가리거나 새 세션으로) |
| Gazebo · VRX | 기동 성공 화면 + 근접 화면 |
| RViz2 | Displays 패널이 함께 보이는 화면 |
| rqt_graph · rqt_image_view | 창 전체 |
| Simulink 모델 | **모델 그림이 아니라 창 전체.** 리본의 실행 버튼·정지 시간이 보여야 한다 |
| MATLAB 그래프 | `print` 로 뽑은 그림 (창 껍데기 불필요) |
| 터미널 출력 | 캡처하지 않는다. 코드블록으로 |

- 원칙 — **학생이 그 도구를 처음 열었을 때 보는 것과 같은 화면**이어야 한다
- 구할 수 없으면 공식 문서의 그림을 링크한다. 출처 없이 가져오지 않는다

### 캡처 방법 (Windows · WSL GUI 공통)


1. 창 제목으로 프로세스를 찾는다. WSLg 창은 `msrdc` 프로세스로 뜬다
2. `ShowWindow(9)` 로 복원하고 `MoveWindow(0,0,W,H)` 로 위치·크기를 정한다
3. `SetForegroundWindow` 로 앞으로 가져온다
4. **저장 직전에 `GetForegroundWindow` 의 제목을 확인한다.** 기대한 창이 아니면 중단한다
5. `GetWindowRect` + `CopyFromScreen` 으로 그 창만 캡처한다
6. 잔상·여백은 `System.Drawing` 으로 잘라낸다

> [!caution] 확인하지 않고 저장하면 남의 창이 찍힌다
> 실제로 겪은 두 가지다.
>
> | 증상 | 원인 | 조치 |
> |---|---|---|
> | 창 크기가 `8 x 1032` 처럼 이상함 | 보조 모니터에 있어 좌표가 **음수** | `MoveWindow` 로 (0,0) 으로 옮긴 뒤 캡처 |
> | 엉뚱한 프로그램이 찍힘 | `SetForegroundWindow` 가 실패해도 조용하다 | **저장 전에 최상위 창 제목을 검사**하고, 아니면 저장하지 않는다 |
>
> 잘못 찍힌 파일은 **즉시 지운다.** 다른 작업 화면에는 공개하면 안 되는 내용이 들어 있을 수 있다.

- Gazebo 카메라는 손으로 옮기지 말고 서비스로 지정한다. 재현된다

```bash
gz service -s /gui/follow --reqtype gz.msgs.StringMsg --reptype gz.msgs.Boolean --timeout 4000 --req 'data: "wamv"'
gz service -s /gui/follow/offset --reqtype gz.msgs.Vector3d --reptype gz.msgs.Boolean --timeout 4000 --req 'x: -7, y: -5, z: 3'
```

- 저장 위치 — `assets/wNN-<내용>.png`. 실제 화면이므로 PNG 가 맞다

### 설치·다운로드 단계

| 대상 | 넣을 것 |
|---|---|
| 내려받기 페이지 | Chrome 헤드리스로 **파일로 저장**한다 (아래) |
| 설치 확인 명령 | 실제 출력을 코드블록으로. 버전 숫자까지 |
| 설치 실패 | **재현해서 받은 진짜 메시지**. 지어내지 않는다 |

```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless --disable-gpu \
  --hide-scrollbars --window-size=1280,860 --virtual-time-budget=9000 \
  --screenshot="$(cygpath -w out.png)" "https://example.com"
```

> [!warning] 봇 차단이 걸린 사이트는 캡처하지 않는다
> ROS 2 공식 문서(docs.ros.org)는 Anubis 로 헤드리스 접근을 막는다.
> 우회하지 말고 **링크만** 싣는다.

### 오류 메시지는 재현해서 받는다

- 기억이나 추측으로 적지 않는다. 학생이 검색할 문자열이 한 글자라도 다르면 소용없다
- 재현 방법의 예

| 오류 | 재현 |
|---|---|
| `command not found` | `env -i bash -c 'ros2 topic list'` |
| `bad interpreter: ^M` | `printf '#!/bin/bash\r\n' > x.sh` 후 실행 |
| `Permission denied` (apt) | `sudo` 없이 `apt install` |
| 토픽이 안 보임 | `ROS_DOMAIN_ID=77 ros2 topic list` |

- 받은 메시지에 **원인 한 줄 + 조치 명령**을 붙여 표로 만든다

## 4. 외부 코드를 가져올 때

> [!caution] 돌려 보지 않은 코드를 싣지 않는다

1. 저장소를 클론하고 **버전을 고정**한다 (태그 또는 커밋)
2. 실제로 실행해 출력을 받는다
3. 출처를 본문에 적는다 — 저장소 링크 · 라이선스 · 태그

```markdown
- 출처 — [`ros2/examples`](https://github.com/ros2/examples) (Apache License 2.0), 태그 `0.15.5`
```

- 라이선스가 재배포를 허용하는지 확인한다. 애매하면 **링크만** 걸고 코드를 복사하지 않는다

## 5. 다이어그램

- 규칙은 `figures-svg.md` 를 따른다 (흰 배경 · 팔레트 · 15pt 이상)
- **그리기 전에 무엇을 보여 줄지 한 문장으로 정한다.** 정하지 못하면 그 그림은 필요 없다
- 그린 뒤 **반드시 렌더해서 눈으로 본다**. 라벨 겹침은 코드만 봐서는 안 보인다

```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless --disable-gpu \
  --screenshot="$(cygpath -w out.png)" --window-size=940,620 \
  --default-background-color=FFFFFF "file:///<절대경로>/그림.svg"
```

- 좋은 다이어그램의 공통점
  - **명령과 그림을 잇는다** — "어느 명령이 어디를 보여 주는가"
  - **틀린 경우를 같이 그린다** — 맞는 그림만 있으면 판별을 못 한다
  - 색으로 계층을 구분한다. 같은 색은 같은 성질
