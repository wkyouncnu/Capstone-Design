# 한 주차를 고치면 열다섯 주차를 고친다

> [!important] 한 문장으로
> **규칙·도구·형식이 바뀌면 그 변화는 전 주차에 적용한다.** 고친 주차 하나만 좋아지면
> 학생이 주차마다 다른 자료를 받는다. 그것이 이 볼트가 가장 피하려는 상태다.

2026-09-16 에 사용자가 지시한 것이다 — **"전체 다 강의 자료도 다 업데이트해줘"**.
한 주차에서 발견한 개선은 그 주차의 것이 아니라 **볼트의 것**이다.

---

## 1. 무엇이 "전 주차 적용" 대상인가

| 바뀐 것 | 전 주차에 적용 | 그 주차만 |
|---|---|---|
| 배치·배선 규칙 (Sum 크기, 꺾임 수, 색) | ✅ 전 모델 재생성 | |
| 문서 골격 (절 순서, 진도 체크, 배점표 형식) | ✅ | |
| 문체·용어 (금지 표현, 기호 표기, 좌표계 이름) | ✅ | |
| 참조 강의 블록, 프론트매터 키 | ✅ | |
| 그림 규약 (SVG 팔레트, 폰트, 흰 배경) | ✅ | |
| 도구 (`_tools/` 함수 추가·변경) | ✅ 쓰는 곳 전부 | |
| 그 주차의 실험 수치·시나리오 | | ✅ |
| 그 주차에만 있는 블록·토픽 설명 | | ✅ |

---

## 2. 순서 — 도구부터, 문서는 마지막

```
1) 규칙을 한 곳에 적는다     CLAUDE.md 또는 스킬 references/
2) 도구를 고친다             _tools/ 의 함수. 검사기부터
3) 전수 조사                 무엇이 규칙을 어기고 있는지 표로 센다
4) 주차별로 고친다           작은 것부터. 주차 하나가 끝나면 검사기 통과 확인
5) 수치를 다시 잰다          구조를 바꿨으면 sim() 을 다시 돌린다
6) 그림을 다시 뽑는다        export_diagram · SVG · 결과 PNG
7) MD 를 갱신한다            바뀐 수치·그림·절 번호
8) PDF 를 전부 다시 뽑는다   bash _tools/pdf_sync.sh
9) README·강의계획서 갱신    쪽수·모델 개수·요약
10) vault_check.sh           0 건
```

> [!warning] 3번(전수 조사)을 건너뛰지 않는다
> "아마 다른 주차도 비슷할 것"으로 시작하면 반드시 빠뜨린다.
> **표를 먼저 만들고**, 그 표의 행을 하나씩 지운다.

### 전수 조사 관용구

```matlab
% 모델 — 규칙 위반을 주차별로 센다
wk = dir(fullfile(root,'10-주차별-강의자료','W*_simulink'));
for i = 1:numel(wk)
    f = dir(fullfile(wk(i).folder, wk(i).name, '*.slx'));
    for k = 1:numel(f)
        [~,m] = fileparts(f(k).name);
        load_system(m);
        fprintf('%-24s %-24s 블록 %3d  지적 %d\n', wk(i).name, m, ...
                numel(find_system(m,'SearchDepth',1,'Type','Block')), check_lines(m));
        close_system(m,0);
    end
end
```

```bash
# 문서 — 표현이나 형식을 주차별로 센다
grep -c "찾을 표현" 10-주차별-강의자료/W*.md
```

## 3. 구조를 바꾼 뒤에는 수치가 같아야 한다

- 서브시스템으로 묶거나 블록을 옮긴 것은 **그림의 변경이지 모델의 변경이 아니다**
- 묶기 **전** 수치를 먼저 기록하고, 묶은 **후** 같은 `sim()` 을 돌린다
- **소수점까지 같아야 한다.** 다르면 배선 순서가 바뀐 것이다 → 포트 번호를 확인

```matlab
before = sim('W06_0_offline');   % 구조 변경 전
% ... 재구조화 ...
after  = sim('W06_0_offline');
max(abs(squeeze(before.log_u.Data) - squeeze(after.log_u.Data)))   % 0 이어야 한다
```

- 수치가 바뀌었다면 **MD 의 모든 숫자를 다시 잰 값으로** 갱신한다. 하나만 고치지 않는다

---

## 4. 절 번호가 밀릴 때

새 절을 중간에 넣으면 뒤 절의 글자·번호가 전부 밀린다. **본문의 상호 참조까지** 밀린다.

1. 뒤에서 앞으로 바꾼다 (H→K, G→J, F→I, E→H). 앞에서부터 하면 이름이 충돌한다
2. 하위 절도 같이 (`### G-1.` → `### J-1.`)
3. **본문 안의 "§B-1 참조", "A절에서" 같은 문장을 `grep` 으로 찾아 고친다**
4. 진도 체크·과제·막혔을 때 표에 절 문자가 있으면 그것도

```bash
grep -n "[A-K]절\|§[A-K]" 10-주차별-강의자료/W06_*.md
```

## 5. 문서 하나를 고쳤으면 같이 보는 곳

| 곳 | 무엇을 |
|---|---|
| `README.md` | 주차 표의 쪽수·요약·배포 모델 개수 |
| `00-운영/강의계획서.md` | 주차 내용이 바뀌었으면 |
| `40-자산/Simulink-모델-인벤토리.md` | 모델을 추가·삭제했으면 |
| `20-지식/` | 새로 발견한 원리는 지식카드로. 제목이 곧 주장 |
| 앞·뒤 주차의 "다음 주 예고" · "지난 주차" | 내용이 바뀌었으면 |
| `_templates/주차자료.md` | 골격을 바꿨으면 **템플릿이 원본이다** |

## 6. 끝내기 전

```bash
bash _tools/pdf_sync.sh
bash .claude/skills/capstone-lecture-vault/scripts/vault_check.sh
```

- `vault_check.sh` 0 건이 아니면 끝난 것이 아니다
