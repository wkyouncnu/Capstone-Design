## 한 줄 요약

> **오프라인 모델은 "비슷한 배"가 아니라 "같은 배"여야 한다.** 그래야 거기서 맞춘 게인이 그대로 통한다.

## 무슨 일이 일어나는가

- 오프라인 모델을 쓰는 이유는 속도임
  - Gazebo 는 이 노트북에서 실시간의 절반 속도로 돎 (RTF ≈ 0.48)
  - 한 조건을 돌리는 데 몇 분. 파라미터 스윕은 하루가 걸림
  - 오프라인 3자유도 모델은 **몇 초** 만에 끝남
- 그런데 모델이 다른 배면 소용없음. **거기서 맞춘 게인이 안 통함**

### 계수를 어디서 가져오는가

- 추측하지 않고 시뮬레이터 설정 파일에서 그대로 읽어옴

| 항목 | 값 | 출처 |
|---|---|---|
| 질량 | 211 kg | `wamv_base.urdf.xacro` 180 + 엔진 2×15 + 프로펠러 2×0.5 |
| 요 관성 | 653 kg·m² | 같은 파일 `izz` 446 + 엔진 이동항 |
| 전후 항력 | `−(100 + 150·│u│)·u` | `SimpleHydrodynamics` 의 `xU`, `xUU` |
| 좌우 항력 | `−(100 + 100·│v│)·v` | `yV`, `yVV` |
| 요 항력 | `−(800 + 800·│r│)·r` | `nR`, `nRR` |
| 부가질량 | **0** | `xDotU = yDotV = nDotR = 0` |
| 프로펠러 | `F = k·n·│n│`, `k = ρ·Ct·D⁴ = 0.0070752` | `wamv_gazebo_thruster_config.xacro` |

### 검산

- 정상상태: `400 N = (100 + 150u)·u` → **u = 1.333 m/s**
- Gazebo 실측 (추력 200+200 N): **1.331 m/s**
- 두 값이 맞으면 항력 모델이 맞다는 뜻

## 왜 중요한가 / 어디에 쓰나

- 2026-09-03 검증 — 동일 유도·제어기·게인·초기조건으로 150 초 주행

| 항목 | 오프라인 | VRX Gazebo | 차이 |
|---|---|---|---|
| 주행거리 | 221.5 m | 227.2 m | +5.7 m |
| 평균 `u` | 1.468 m/s | 1.467 m/s | −0.000 |
| **정상상태 `u`** | **1.500 m/s** | **1.500 m/s** | **0.000** |
| 60초 이후 평균 \|y_e\| | 0.625 m | 0.680 m | +0.055 |
| 궤적 평균 이격 | | | **3.67 m** |
| 궤적 최대 이격 | | | **5.51 m** |

- 227 m 를 달린 뒤 평균 3.7 m 차이. 경로 길이의 **1.6 %**
- 정상상태 속도는 소수점 셋째 자리까지 같음
- **게인을 하나도 바꾸지 않았음**
- 차이는 주로 **모서리를 도는 타이밍**에서 생김. 직선 구간에서는 거의 겹침

### 작업 순서가 달라진다

1. 오프라인에서 파라미터를 마음껏 스윕 (몇 초)
2. 가장 좋은 값을 고름
3. VRX 에서 **확인만** 함 (몇 분)

> [!warning] 실시간 계수(RTF)를 맞추지 않으면 결과가 어긋난다
> Gazebo 가 실시간의 절반 속도로 돌면, Simulink 를 벽시계에 맞춰 페이싱했을 때
> 배는 시뮬레이션 시간을 절반밖에 살지 못한다.
> 증상: **주행거리 ÷ 시간이 `u` 평균과 2배 차이 난다.**
> 해결: RTF 를 측정해 `PacingRate` 를 그 값으로 설정한다.

> [!important] 포화는 게인 문제로 위장한다
> 이 검증 과정에서 실제로 겪은 일이다. 추력 한계를 250 N 으로 두었더니
> **77 % 의 시간을 포화 상태**로 보냈다. 1.5 m/s 유지에만 편당 244 N 이 들어
> 선회할 여유가 없었던 것이다. 게인을 20배까지 올려도 성능이 나아지지 않았다.
> 한계를 500 N 으로 올리자 포화가 0 % 가 되고 이탈량이 절반이 되었다.
> **게인을 만져도 안 나아지면 포화부터 확인할 것.**

> [!note] 모든 물리를 옮길 수는 없다
> 부력·파랑·바람은 오프라인 3자유도 모델에 없다. 반대로 **조류는 오프라인에만** 있다
> (VRX 에 해류 플러그인이 없음). 무엇이 같고 무엇이 다른지 알고 쓰는 것이 중요하다.
