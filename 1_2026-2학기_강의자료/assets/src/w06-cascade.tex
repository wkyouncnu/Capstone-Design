%
% 이 그림이 말하는 것
%   제어기가 하나가 아니라 **둘이 겹쳐 있다**. 바깥은 "어디로 갈까"를 정하고,
%   안쪽은 "얼마나 세게 밀까"를 정한다. 바깥이 안쪽에게 주는 것은 추력이
%   아니라 **속도 지령**이다 — 이것이 캐스케이드(다단) 제어의 전부다.
%
% 2026-10-15 다시 그림 — 앞 판은 한 축짜리 일반형이라 6주차 모델과 달랐다.
%   실제 모델(parts/addOuterLoop.m + parts/addInnerLoop.m)과 블록을 맞춘다.
%
%     바깥 고리  (x_ref, y_ref) - (x_n, y_n) = (e_N, e_E)  [m]    <- NED 축
%                --(회전 R(psi)^T)-->  (e_x, e_y)          [m]    <- 선체 축
%                --(P: Kp_x, Kp_y)-->  (u_d, v_d)          [m/s]
%                --(포화 u_max, v_max)--> --(x gate)--> (u_cmd, v_cmd)
%     안쪽 고리  (u_cmd, v_cmd) - (u, v)                   [m/s]
%                --(PI: Kp_u Ki_u / Kp_v Ki_v)--> (X, Y)   [N]
%                --(추력 배분)--> (F_L, F_R, F_B)          [N]
%
%   앞 판에 없어서 틀렸던 것 셋
%     (1) 위치 목표가 한 개(p_d)로 그려져 있었다. 실제로는 북·동 두 개다
%     (2) **회전행렬이 빠져 있었다.** 바깥 고리의 오차는 북·동으로 몇 m 이고
%         안쪽 고리가 쥐는 것은 앞·옆으로 몇 m/s 다. 두 자가 psi 만큼 돌아가
%         있으므로 사이에 R(psi)^T 가 반드시 한 번 들어간다
%     (3) 안쪽 고리가 제어하는 것이 u 하나로 그려져 있었다. u 와 v 둘이다
%
% 좌표 메모 (mm)
%   주 경로 y=0 · 안쪽 되먹임 y=-30 · 바깥 되먹임 y=-48 · psi 줄 y=-64
%   합산점 x = 0 / 206 · 블록 x = 38 / 86 / 136 / 174 / 246 / 292 / 340
%   블록 폭 26 (반 13) 이므로 사이 틈이 최소 21 mm — 두 줄짜리 신호 이름이 들어간다
%   글자는 \footnotesize — 앞 판은 \scriptsize 라 확대해도 읽기 힘들었다

\node[anchor=north west, font=\footnotesize, text width=130mm] at (96,-84)
     {\textbf{왜 하나로 하지 않고 둘로 나누는가} \\[3pt]

      $\bullet$ 이득의 단위가 갈린다. 바깥 $K_{p,x}$ 는 $1/\mathrm{s}$,
        안쪽 $K_{p,u}$ 는 $\mathrm{N}/(\mathrm{m/s})$ — 서로 섞이지 않는다 \\[2pt]
      $\bullet$ 위치 오차에서 추력을 바로 뽑으면 \textbf{배가 얼마나 빨리
        가는지를 제어기가 모른다}. 멀리서 세게 밀면 계속 빨라지기만 한다};

      고리의 양 끝에 둔다. \texttt{w06-ned-loop} 와 견주어 볼 것};
